# DSA Interview Questions 51-100 (Service-Based Companies)

A second set of 50 questions, continuing from the array list (Q1-45). This set covers the topics most asked by service-based companies like TCS, Infosys, Accenture, Cognizant and Fidelity. Trees, graphs and hard-level problems are intentionally excluded.

## How to Use This List

- Work through the sections in order. Strings and math build the logic you need for hashing, linked lists and recursion later.
- Time yourself: aim for 10-15 minutes per easy question and 25-30 minutes per medium one.
- Explain your approach out loud or in comments, as you would in a real interview.
- For every question, try the brute-force version first, then improve it and note the time and space complexity.
- Revisit missed questions after a few days to check retention.

## Questions

### 1. Strings (Easy-Medium)
51. Reverse a string.
52. Check if a string is a palindrome.
53. Check if two strings are anagrams.
54. Count vowels, consonants, digits and special characters in a string.
55. Find the frequency of each character in a string.
56. Find the first non-repeating character.
57. Remove duplicate characters from a string.
58. Reverse the words in a sentence.
59. Find the longest word in a sentence.
60. Check if one string is a rotation of another.
61. Compress a string (e.g. `aaabb` -> `a3b2`).
62. Find the longest common prefix among an array of strings.
63. Toggle the case of every character in a string.
64. Find the longest palindromic substring.

### 2. Math and Number Problems (Easy)
65. Check if a number is prime.
66. Print all prime numbers up to N (Sieve of Eratosthenes).
67. Print the first N Fibonacci numbers.
68. Find the factorial of a number (iterative and recursive).
69. Find the GCD and LCM of two numbers.
70. Check if a number is an Armstrong number.
71. Check if a number is a palindrome, and reverse a number.
72. Convert a decimal number to binary, and binary back to decimal.

### 3. Patterns (Easy)
73. Print a right-angled star pyramid and an inverted one.
74. Print a number pyramid and Floyd's triangle.
75. Print Pascal's triangle.

### 4. Sorting and Searching (Easy-Medium)
76. Implement bubble sort, selection sort and insertion sort.
77. Implement merge sort.
78. Implement quick sort.
79. Implement linear search and binary search (iterative and recursive).

### 5. Hashing (Easy-Medium)
80. Find the first repeating element in an array.
81. Group anagrams together from a list of words.
82. Find the longest consecutive sequence in an unsorted array.
83. Check if two arrays are equal (same elements, any order).

### 6. Linked List (Medium)
84. Reverse a singly linked list.
85. Find the middle of a linked list.
86. Detect a cycle in a linked list.
87. Merge two sorted linked lists.
88. Remove the nth node from the end.
89. Check if a linked list is a palindrome.

### 7. Stack and Queue (Easy-Medium)
90. Check for balanced parentheses.
91. Implement a stack using an array and using a queue.
92. Implement a queue using two stacks.
93. Find the next greater element for each array element.
94. Evaluate a postfix expression.

### 8. Recursion and Basic DP (Medium)
95. Print all subsets of an array (power set).
96. Generate all permutations of a string.
97. Climbing stairs (count ways to reach step N).
98. 0/1 Knapsack.
99. Longest common subsequence.
100. Coin change (minimum coins for an amount).

## Priority Guide

- **Q51-83 (strings, math, patterns, sorting, hashing):** The core. Most TCS Ninja, Accenture and Infosys SE coding questions come from here, so do these first.
- **Q84-94 (linked list, stack, queue):** More important for TCS Digital/Prime, Infosys DSE/SP, Cognizant Elevate and Fidelity.
- **Q95-100 (recursion and DP):** The hardest in this set. Take them last, and make sure you understand recursion before attempting DP.

## Notes

- Q64 (longest palindromic substring) and Q82 (longest consecutive sequence) lean toward medium. Skip them at first if you're short on time.
- Heaps, tries, segment trees and advanced DP rarely appear in service-based company rounds, so they are left out here.
- Practice in your primary interview language and write full runnable code, not just pseudocode. Service-based company tests are usually timed online coding rounds.
- Alongside DSA, prepare aptitude (quant, logical, verbal), basic SQL and DBMS, OOP concepts, and common HR questions.
